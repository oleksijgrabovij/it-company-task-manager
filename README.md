# IT Company Task Manager

A web application built with Django for managing internal tasks, workers, positions, and task types within an IT company.

## Features
- **User Authentication**: Secure login and registration system for employees.
- **Task Management**: Create, update, delete, and view tasks with priorities, deadlines, and assigned workers.
- **Worker Management**: Track workers, their positions, and assigned tasks.
- **Search & Filtering**: Filter tasks by title and type, and workers by username and position.
- **Responsive UI**: Styled using Bootstrap 5 and django-crispy-forms.

## Tech Stack
- **Python / Django**
- **SQLite**
- **Bootstrap 5**
- **Flake8** (for code linting)
